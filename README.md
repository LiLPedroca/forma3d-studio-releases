# Forma3D Studio

Downloads oficiais para Windows 10/11 de 64 bits.

## Instalar e atualizar

1. Abra [a versão mais recente](https://github.com/LiLPedroca/forma3d-studio-releases/releases/latest).
2. Salve seus projetos e feche as versões portáteis antigas.
3. Execute o arquivo Forma3D-Setup da versão. Esta instalação é necessária uma única vez.
4. Depois, abra pelo atalho do Windows. O aplicativo busca novas versões automaticamente e mostra o botão Atualizações.
5. Quando o download terminar, escolha Reiniciar e atualizar. O programa protege projetos não salvos antes de reiniciar.

A modelagem funciona offline. Internet é necessária apenas para buscar e baixar atualizações.

Este repositório distribui somente instaladores e metadados. O código do aplicativo fica em um repositório privado.
